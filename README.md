# IRONPEAK Strength System

Versão 6.1.1: biblioteca de presets incorporada ao aplicativo para evitar falha de carregamento do JSON externo.

## Publicação no GitHub Pages
Envie o conteúdo desta pasta para a raiz do repositório, substituindo os arquivos correspondentes e mantendo a pasta `presets`. Não envie o ZIP fechado.

Os modelos Básico, Intermediário e Avançado são preservados como origem. Ao criar uma cópia, as alterações ficam no armazenamento local deste navegador. As fórmulas do Excel são preservadas como texto, sem recálculo.
